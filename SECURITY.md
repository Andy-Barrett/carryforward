# Security and customer data

CarryForward is an early local prototype. It has not been reviewed for production customer data. The server binds to loopback, and the included records are fictional.

Do not put API keys, account tokens, customer records, recordings, or service photos in issues or pull requests. Browser drafts are local to the device and are not encrypted application storage or a backup.

If you find a security issue, email Andy at **andy@perihelionsolar.com** with a description and steps to reproduce using synthetic data. Do not include real credentials or customer content. I’ll coordinate a private follow-up if more detail is needed.
